## 🔄 How to Use

### Adding Data
1. Click "Add [Item]" button
2. Fill in the form
3. Click submit
4. Data appears in list/table

### Searching & Filtering
1. Type in search box
2. Use dropdown filters
3. Results update instantly
4. Export if needed

### Viewing Details
1. Click "View Details" or "View"
2. Modal opens with full information
3. Close with X button

### Editing Data
1. Click "Edit" button
2. Form opens with current data
3. Update fields
4. Submit changes

### Deleting Data
1. Click "Delete" button
2. Confirm in dialog
3. Item removed from list
4. Can't undo - be careful!

## 🎯 Common Tasks

### Add a New Worker
```
1. Go to /admin/workers
2. Click "Add Worker"
3. Fill: Name, Phone, Service, Location
4. Click "Add Worker"
5. Worker appears in table
```

### Check Revenue Trends
```
1. Go to /admin/analytics
2. See Daily Revenue chart
3. Use dropdown to change time range
4. Click "Export Report"
```

### Configure Pricing
```
1. Go to /admin/settings
2. Click "Services" tab
3. Set Min/Max price, Commission, Tax
4. Click "Save Changes"
```

### Resolve a Complaint
```
1. Go to /admin/complaints
2. Click "View Details"
3. Type response
4. Click "Send Response"
5. Status changes to Resolved
```
